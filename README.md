# Рифмовник

Поиск рифм по звучанию и каталог панчей, русский и украинский.

Открыть: https://vtrendemusic.info/rifmovnik/

- **Рифмы.** Пишешь слово или фразу и получаешь созвучия: точные, близкие и «на грани». Учитываются ударная гласная, редукция безударных и оглушение согласных, а также составные и многосложные рифмы и англицизмы. Ударение можно отметить заглавной буквой (`дЕньги`) или плюсом (`д+еньги`).
- **Панчи.** Омонимы, отсылки, игра слов и двойной смысл, с пояснениями.

Статическая страница: данные лежат в `data/*.json`, сервер не нужен.
